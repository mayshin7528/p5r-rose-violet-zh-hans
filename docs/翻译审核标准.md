# Rose & Violet 中文翻译审核标准

## 语义优先级

1. 原 Mod 英文是语义基准，必须逐句读取。
2. 官方简体中文只用于术语、角色口吻、标点和中文表达风格。
3. `match_class`、路径和消息 ID 只用于结构对齐，不能证明中英语义一致。
4. `EXACT_OFFICIAL_PROXY` 不得自动判定为“沿用官中”或“审核通过”。
5. 没有明确逐句审核记录的译文，无论是否已有 override，一律标为“待核对”。

## 审核要求

- 按同一资源内的上下文确认说话人、指代、性别、人物关系和选项分支。
- 主角是芳泽霞；Mod 英文中的 Sumire 是芳泽堇。
- 动态姓名和其他控制码必须原样保留，不得写死或翻译。
- 普通对话每页优先使用 0 到 1 个换行，最多 2 个；只在标点或自然短语边界换行。
- `Dummy`、测试占位和内部结构文本保持原样，不计为未翻译正文。

## 审核状态

- `通过`：已实际对照原 Mod 英文及上下文。
- `待核对`：结构已对齐，但尚未完成语义核对。
- `待修复`：已发现语义、说话人、控制码、消息头或语言残留错误。

旧报告仅作为历史线索，不再作为译文正确性的依据。
